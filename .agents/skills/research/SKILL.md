---
name: research
description: "Investigate a requested question using primary sources and save concise cited findings."
---

Investigate with the current agent. Use a background agent only when the user
requests delegation and independent work can proceed alongside it.

Prefer primary sources: official documentation, papers, specifications, and source
code. For project facts, follow root AGENTS.md's authority order. Retrieve only
what changes the answer; distinguish source-backed findings from inference.

Save durable findings in the existing relevant document, or the user's requested
research note. Include the answer, citations, important uncertainty and practical
implication. For a question answered in conversation, do not create an extra report
just to repeat it. Record substantive outcomes and any next action in WORK_LOG.md;
link scientific notes rather than copying them. No separate spec, tickets or vault
update unless requested.
