# vit_base_patch16_224 на AID: учёт активаций и индивидуальные ранги

## Предмет исследования и гипотеза

Проверяем, уменьшает ли локальный критерий на train-активациях ошибку преобразований и улучшает ли качество всей модели при тех же рангах. Отдельно проверяем распределение рангов при точно равном хранении. Локальный оптимум не гарантирует оптимума нелинейной модели.

## Исходные данные

Один исходный checkpoint vit_base_patch16_224, SHA-256 `a93c5cf00c34b25212a81fcee07432024731a9932f071cf6ccf9dba1ec7c30e4`; AID, 30 классов, seed 42, неизменный split 7000/1500/1500. Исходная validation accuracy 97.133%, CE 0.197622. Калибровка: 300 train-изображений (10 каждого класса), выбор NumPy default_rng(42), фиксированный resize/normalization без аугментаций. Все 197 токенов изображения имеют одинаковый вес; 59100 строк для каждой матрицы. Независимые локальные ошибки и качество модели — на тех же 1500 validation-изображениях. Test не читался.

## Математическая постановка

Для $Y=XW$, $C=X^\top X/N$ (нецентрированный момент). Обычный SVD минимизирует $\|W-\widetilde W\|_F^2$; новый критерий — $\operatorname{tr}((W-\widetilde W)^\top C(W-\widetilde W))$. Используем $C_\lambda=C+\lambda I$, $\lambda=10^{-4}\operatorname{tr}(C)/n$: к MSE на токен добавляется $\lambda\|W-\widetilde W\|_F^2$. Это регуляризованный локальный критерий, не точный нерегуляризованный минимум.

В хранимой ориентации $(out,in)$: $C_\lambda=LL^\top$, $B=W_sL=U\Sigma V^\top$, $F_2=U_r\sqrt{\Sigma_r}$, $F_1=\sqrt{\Sigma_r}V_r^\top L^{-1}$. Инференс вычисляет $(XF_1^\top)F_2^\top+b$. Bias сохранён; расширяющие и полные ранги не пропускаются. Обратная матрица явно не строится: используется треугольное решение в float64, факторы хранятся в float32.

Моменты суммируются потоково: float32 Gram по batch с highest precision, float64 сумма на CPU; все активации не сохраняются. Численная PSD-проекция разрешена только для погрешности округления и протоколируется. PSD-проекция потребовалась для 5 матриц; λ от 2.31e-06 до 0.0159, максимум обусловленности регуляризованного момента 2.11e+07. Значения для каждой матрицы сохранены в diagnostics.json.

## Варьируемые параметры и метрики

Ранги: 0.125, 0.25, 0.375, 0.5, 0.625, 0.75, 0.875, 1.0; фактический целый ранг = floor(ρ min(out,in)). 24 глобальные конфигурации attn/ffn/all_blocks, 48 региональных (блоки 0–3/4–7/8–11), 96 одиночных (блоки 0/5/11 × qkv/proj/fc1/fc2). Голова исключена. Все 168 пар имеют одинаковые веса, матрицы, ранги, параметры, validation-пиксели и протокол. Обычные SVD-оценки взяты из парной серии.

Метрики: абсолютная/относительная Frobenius-ошибка весов, MSE преобразования на токен и относительный RMSE отдельно на train-calibration/validation, средняя/P95 L2-ошибка логитов, относительная Frobenius/максимальная абсолютная ошибка логитов, top-1, несглаженная CE, параметры, байты массивов и NPZ. Локальная ошибка не включает bias и измеряется на входах исходной модели; после одновременных замен входы следующих блоков меняются.

### Индивидуальные ранги

Точное multiple-choice knapsack (динамическое программирование): одна из восьми ранговых точек для каждой матрицы; минимизируем сумму **ненормированных** calibration MSE вычисленных факторов при точном равенстве суммарного r(out+in). Bias и прочие параметры постоянны. Для каждого бюджета сравниваются uniform/allocated × ordinary/activation SVD. При равных значениях используется детерминированный порядок. Ошибки разных блоков аддитивны только в этом суррогатном критерии; их сумма не равна ошибке сети. Ранговые карты лежат в matrix_errors.csv и исходных allocation.json.

## Ограничения

Один checkpoint, seed и split; calibration из 300 изображений не покрывает всё train-распределение. λ фиксирован до запусков, чувствительность к нему не изучалась. Подбор/выбор по одной validation может завышать качество выбранных точек. Равные ρ между разными наборами не дают равных бюджетов; в бюджетной таблице равенство проверено точно. Меньшая локальная ошибка и сумма локальных ошибок не гарантируют меньшей ошибки логитов/CE или большей accuracy. Малые различия в несколько изображений не доказывают преимущества. Здесь нет измерений ускорения или пика GPU; test по заданию остаётся нетронутым. Матричные/локальные ошибки относятся к исходной факторизации до дообучения; после дообучения измеряется полная модель. Масштабы факторов после обратного преобразования отличаются от обычного SVD; одинаковый оптимизатор не устраняет влияние этой параметризации на дообучение.
