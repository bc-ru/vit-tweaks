# Exact-SVD vit_base_patch16_224 на AID

Измерено validation: 168/168 конфигураций; исходная модель отдельно. Глобальные: 24/24; области: 48/48; одиночные: 96/96. Дообучений: 10/10 (9 факторов + dense control). Benchmark: 16/16 строк.

Исходная accuracy: 0.97133333; cross-entropy: 0.19762194; параметров: 85821726. Все оценки — 1500 одинаковых validation-изображений; test не исполнялся. Seed 42, split 7000/1500/1500; checkpoint SHA-256 `a93c5cf00c34b25212a81fcee07432024731a9932f071cf6ccf9dba1ec7c30e4`.

Ошибка матриц — аналитический хвост точной float32 SVD с float64 суммированием энергии (этап 02). `matrix_errors.csv` содержит каждую заменённую матрицу и действительный ранг. Среднее Frobenius в общей таблице — невзвешенное среднее относительных ошибок, а не ошибка композиции модели. Факторы симметричны sqrt(S), bias сохранён, высокие ранги не пропускаются.

Полный ранг: 21 контролей; максимум относительной ошибки логитов 1.57e-06, максимум абсолютной разности 2.62e-05. Контроли прошли допуски 5e-5 и 1e-3 соответственно.

## Наблюдения по измерениям

- `all_blocks`: наибольшая измеренная accuracy среди точек с меньшим числом параметров — 96.200% при ранге 0.625, 71665950 параметров (16.49% меньше исходной модели).
- `attn`: наибольшая измеренная accuracy среди точек с меньшим числом параметров — 97.000% при ранге 0.625, 84052254 параметров (2.06% меньше исходной модели).
- `ffn`: наибольшая измеренная accuracy среди точек с меньшим числом параметров — 96.800% при ранге 0.75, 82282782 параметров (4.12% меньше исходной модели).
- `attn`, ранг 0.5: accuracy от 96.933% (middle) до 97.267% (early) при одинаковом числе замен и параметров.
- `ffn`, ранг 0.5: accuracy от 96.867% (late) до 96.933% (middle) при одинаковом числе замен и параметров.
- Дообучение SVD-моделей: изменение accuracy от +0.067 до +76.667 процентных пункта. Все сравнения до/после сделаны на одной validation; dense control показан отдельно.
- `dense_control`: CE ухудшилась 0.197622 → 0.203863 при выборе по accuracy; восстановление качества нельзя считать однозначным по всем метрикам.
- Плотный контроль с теми же 5 эпохами: accuracy 97.133% → 97.267%, CE 0.197622 → 0.203863. Сам эффект дополнительного обучения следует учитывать при сравнении с SVD + дообучение.
- `early_ffn_r0500`: CE ухудшилась 0.207830 → 0.211922 при выборе по accuracy; восстановление качества нельзя считать однозначным по всем метрикам.
- `global_ffn_r0500`: CE ухудшилась 0.183791 → 0.202424 при выборе по accuracy; восстановление качества нельзя считать однозначным по всем метрикам.
- `late_ffn_r0500`: CE ухудшилась 0.137444 → 0.205641 при выборе по accuracy; восстановление качества нельзя считать однозначным по всем метрикам.
- `all_blocks`, ранг 0.5, batch 1: 3.767 ms против 4.337 ms у dense; отношение скорости dense/SVD = 1.152. Уменьшение параметров не обеспечивает ускорение для каждого batch.

## Допустимые выводы и ограничения

Изменение accuracy измеряется для одного checkpoint, seed и validation split: статистической гарантии для других обучений нет. Малая ошибка матриц сама по себе не доказывает малую ошибку модели. Выбор по validation может завышать оценку выбранного варианта; финальный test остаётся отдельным этапом. Дообучение оценивается по факту, без предположения восстановления.

Benchmark: RTX 4070, float32, batches 1/16, 5 прогревов и 50 синхронизированных повторов. Компиляция, подготовка изображений и переносы исключены. Байты параметров и размер NPZ — разные измерения; inference GPU peak не измерен и не заменяется пиком процесса. Скорость нельзя выводить из числа параметров.

Все численные данные: `configurations.csv`, `matrix_curves.csv`, `matrix_errors.csv`, `finetuning.csv`, `benchmarks.csv`; исходные manifests перечислены в manifest данного отчёта. Незавершённые стадии не включены.


Checkpoints дообучения выбирались среди эпох 1–5; исходная точка сохранена отдельно. Benchmark относится к плотному источнику и исходным SVD-checkpoint до дообучения. Различия в несколько изображений на validation не доказывают статистически значимого преимущества.
