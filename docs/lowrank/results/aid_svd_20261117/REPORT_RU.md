# Exact-SVD ViT-Small на AID

Измерено validation: 168/168 конфигураций; исходная модель отдельно. Глобальные: 24/24; области: 48/48; одиночные: 96/96. Дообучений: 10/10 (9 факторов + dense control). Benchmark: 16/16 строк.

Исходная accuracy: 0.97333333; cross-entropy: 0.19847445; параметров: 21677214. Все оценки — 1500 одинаковых validation-изображений; test не исполнялся. Seed 42, split 7000/1500/1500; checkpoint SHA-256 `e5d9e02734f1a7233dcb35c67e8fb0491c26bbf14f2a23d7f38d8d13e5ba9391`.

Ошибка матриц — аналитический хвост точной float32 SVD с float64 суммированием энергии (этап 02). `matrix_errors.csv` содержит каждую заменённую матрицу и действительный ранг. Среднее Frobenius в общей таблице — невзвешенное среднее относительных ошибок, а не ошибка композиции модели. Факторы симметричны sqrt(S), bias сохранён, высокие ранги не пропускаются.

Полный ранг: 21 контролей; максимум относительной ошибки логитов 1.71e-06, максимум абсолютной разности 3.22e-05. Контроли прошли допуски 5e-5 и 1e-3 соответственно.

## Наблюдения по измерениям

- `all_blocks`: наибольшая измеренная accuracy среди точек с меньшим числом параметров — 92.933% при ранге 0.625, 18138270 параметров (16.33% меньше исходной модели).
- `attn`: наибольшая измеренная accuracy среди точек с меньшим числом параметров — 96.467% при ранге 0.625, 21234846 параметров (2.04% меньше исходной модели).
- `ffn`: наибольшая измеренная accuracy среди точек с меньшим числом параметров — 96.600% при ранге 0.75, 20792478 параметров (4.08% меньше исходной модели).
- `attn`, ранг 0.5: accuracy от 96.467% (early) до 96.600% (middle) при одинаковом числе замен и параметров.
- `ffn`, ранг 0.5: accuracy от 94.600% (early) до 97.000% (late) при одинаковом числе замен и параметров.
- Дообучение SVD-моделей: изменение accuracy от +0.267 до +80.200 процентных пункта. Все сравнения до/после сделаны на одной validation; dense control показан отдельно.
- Плотный контроль с теми же 5 эпохами: accuracy 97.333% → 97.200%, CE 0.198474 → 0.194658. Сам эффект дополнительного обучения следует учитывать при сравнении с SVD + дообучение.
- `middle_ffn_r0500`: CE ухудшилась 0.206717 → 0.219062 при выборе по accuracy; восстановление качества нельзя считать однозначным по всем метрикам.
- `all_blocks`, ранг 0.5, batch 1: 1.810 ms против 1.746 ms у dense; отношение скорости dense/SVD = 0.965. Уменьшение параметров не обеспечивает ускорение для каждого batch.
- `all_blocks`, ранг 0.5, batch 16: 11.550 ms против 13.400 ms у dense; отношение скорости dense/SVD = 1.160. Уменьшение параметров не обеспечивает ускорение для каждого batch.

## Допустимые выводы и ограничения

Изменение accuracy измеряется для одного checkpoint, seed и validation split: статистической гарантии для других обучений нет. Малая ошибка матриц сама по себе не доказывает малую ошибку модели. Выбор по validation может завышать оценку выбранного варианта; финальный test остаётся отдельным этапом. Дообучение оценивается по факту, без предположения восстановления.

Benchmark: RTX 4070, float32, batches 1/16, 5 прогревов и 50 синхронизированных повторов. Компиляция, подготовка изображений и переносы исключены. Байты параметров и размер NPZ — разные измерения; inference GPU peak не измерен и не заменяется пиком процесса. Скорость нельзя выводить из числа параметров.

Все численные данные: `configurations.csv`, `matrix_curves.csv`, `matrix_errors.csv`, `finetuning.csv`, `benchmarks.csv`; исходные manifests перечислены в manifest данного отчёта. Незавершённые стадии не включены.


Checkpoints дообучения выбирались среди эпох 1–5; исходная точка сохранена отдельно. Benchmark относится к плотному источнику и исходным SVD-checkpoint до дообучения. Различия в несколько изображений на validation не доказывают статистически значимого преимущества.
