# Заметки для отчёта: спектральный анализ и малоранговая аппроксимация матриц visual encoder

## 1. Рабочая формулировка

Текущий эксперимент следует формулировать не как сравнение моделей, а как исследование численных свойств матриц, возникающих в визуальных нейросетевых энкодерах.

**Объект исследования:** матрицы весов слоёв ViT-Small, ViT-Base и ResNet-18 после fine-tuning на aerial imagery.

**Предмет исследования:** сингулярный спектр, численный ранг, стабильный ранг, обусловленность и ошибка малоранговой SVD-аппроксимации.

**Роль aerial imagery:** предметная область, на которой получаются обученные матрицы. Датасет не является центральным объектом исследования.

## 2. Связь с курсом “Алгебраические вычисления, тензоры и оптимизация”

Работа напрямую использует темы курса:

1. SVD и наилучшее малоранговое приближение.
2. Рандомизированное SVD.
3. Матричные крестовые / скелетные аппроксимации как дальнейшее развитие.
4. Ускорение матрично-векторного умножения при наличии малорангового представления.
5. Тензоризация и Tucker/TT-разложения как следующий этап.
6. Анализ чувствительности Соболя для ранжирования слоёв по влиянию параметров сжатия.

## 3. Математическая база

Для матрицы слоя

\[
W \in \mathbb{R}^{m \times n}
\]

используется сингулярное разложение

\[
W = U\Sigma V^\top.
\]

Усечённое приближение ранга \(r\):

\[
W_r = U_r \Sigma_r V_r^\top.
\]

Относительная ошибка во фробениусовой норме:

\[
E_F(r)=\frac{\|W-W_r\|_F}{\|W\|_F}
= \left(\frac{\sum_{i>r}\sigma_i^2}{\sum_i \sigma_i^2}\right)^{1/2}.
\]

Относительная ошибка в спектральной норме:

\[
E_2(r)=\frac{\|W-W_r\|_2}{\|W\|_2}
=\frac{\sigma_{r+1}}{\sigma_1}.
\]

Стабильный ранг:

\[
r_{\mathrm{stable}}(W)=\frac{\|W\|_F^2}{\|W\|_2^2}.
\]

Ранг, сохраняющий долю энергии \(\tau\):

\[
r_\tau = \min\left\{r:\frac{\sum_{i=1}^{r}\sigma_i^2}{\sum_i\sigma_i^2}\geq \tau\right\}.
\]

Число обусловленности с численным порогом:

\[
\kappa_\varepsilon(W)=\frac{\sigma_1}{\sigma_{r_\varepsilon}},
\]

где \(r_\varepsilon\) — последний индекс, для которого сингулярное число выше выбранного численного порога.

## 4. Эксперимент 1: спектральный паспорт матриц

Для каждого слоя строится таблица:

| Model | Layer | Kind | Shape | Stable rank | Cond eps | r90 | r95 | r99 |
|---|---|---|---:|---:|---:|---:|---:|---:|

Цель: определить, какие группы слоёв имеют быстро убывающий сингулярный спектр и допускают малоранговое представление.

Интерпретация:

- малый \(r_{0.95}/r_{max}\) означает хорошую потенциальную сжимаемость;
- большой \(\kappa_\varepsilon\) указывает на возможную численную неустойчивость;
- стабильный ранг показывает эффективную размерность матрицы с учётом распределения энергии по сингулярным направлениям.

## 5. Эксперимент 2: кривые ошибки аппроксимации

Строятся зависимости:

\[
E_F(r), \quad E_2(r)
\]

от:

1. ранга \(r\),
2. относительной стоимости хранения

\[
C(r)=\frac{r(m+n)}{mn}.
\]

Цель: показать, насколько быстро падает ошибка при росте ранга и насколько выгодно хранение \(U_r,\Sigma_r,V_r\) вместо полной матрицы.

Важный вывод:

> параметрическое сжатие не тождественно ускорению инференса; это отдельная гипотеза, требующая проверки.

## 6. Эксперимент 3: randomized SVD против полного SVD

Для крупных матриц сравниваются:

- время полного SVD;
- время randomized SVD;
- относительная ошибка сингулярных чисел;
- ошибка аппроксимации.

Цель: проверить, применимы ли алгоритмы randomized SVD для анализа и сжатия больших матриц visual encoder.

## 7. Эксперимент 4: локальная ошибка выхода слоя

Матрица слоя заменяется приближением:

\[
W \rightarrow W_r.
\]

Для реальных активаций \(x\) из датасета измеряется:

\[
\delta_{layer}=\frac{\|Wx-W_rx\|_2}{\|Wx\|_2}.
\]

Это связывает ошибку матричной аппроксимации с фактической ошибкой оператора на данных.

Ключевая исследовательская мысль:

> малая ошибка \(\|W-W_r\|_F\) не гарантирует малую ошибку выхода слоя; важна ориентация входных активаций относительно отброшенных сингулярных направлений.

## 8. Как использовать уже полученные accuracy / latency / memory

Эти метрики остаются, но перестают быть центральными.

Правильная роль:

- accuracy drop — глобальный эффект локальной матричной аппроксимации;
- latency — проверка практического эффекта теоретического сокращения операций;
- memory/checkpoint size — проверка выигрыша по хранению;
- throughput — инженерное дополнение, не главный результат.
