# План презентации: вычислительно-математический разворот эксперимента

## Слайд 1. Мотивация

- Долгосрочная тема: управление БЛА по визуальной информации.
- Текущий фокус: visual encoder как вычислительный оператор.
- Вопрос: имеют ли матрицы visual encoder малоранговую структуру?

## Слайд 2. Объект исследования

- ViT-Small, ViT-Base, ResNet-18 после fine-tuning на aerial imagery.
- Модель не является целью.
- Матрицы слоёв являются объектами вычислительной линейной алгебры.

## Слайд 6. Randomized SVD

Показать таблицу:

| Layer | Full SVD time | Randomized SVD time | Sigma error | Fro error |

Тезис:

> randomized SVD — естественный следующий алгоритм для больших матриц.

## Слайд 7. Локальная ошибка слоя

Формула:

\[
\delta_{layer}=\frac{\|Wx-W_rx\|_2}{\|Wx\|_2}.
\]

Вставить график:

- matrix approximation error vs layer-output error.

Тезис:

> ошибка матрицы и ошибка действия матрицы на реальных данных — разные, но связанные величины.

## Слайд 8. Связь с уже полученными model metrics

- accuracy drop = глобальный эффект замены матриц;
- latency = проверка теоретического выигрыша на практике;
- memory/checkpoint = выигрыш хранения.

Не главный вопрос: какая модель лучше.

Главный вопрос:

> какие операторы допускают устойчивую низкоранговую замену?

## Слайд 9. Следующие шаги

1. Adaptive rank selection.
2. Randomized SVD на всех крупных слоях.
3. Cross approximation.
4. Tucker/TT после тензоризации весов.
5. Sobol sensitivity по рангам групп слоёв.
6. Встраивание compact encoder в RL-policy.

## Слайд 10. Итог

Формулировка:

> Проведён переход от engineering benchmark к вычислительно-математическому анализу матриц visual encoder: спектры, ранги, обусловленность, ошибки аппроксимации и эффект на выходы слоёв.
