# ViT low-rank experiments

Truncated-SVD approximation of trained ViT weights on AID. The current protocol
uses **JAX, ViT-Small, 30 classes**, and the frozen seed-42 train/validation/test
split. Matrix error, local operator error and classification quality are separate
measurements. The older Torch compression benchmark remains a compatibility path.

Legacy root output names (`runs/`, `checkpoints/`, `results/`, etc.) are compatibility
links into `artifacts/`, so existing configs, split references and commands keep
working. New results belong in `artifacts/experiments/<id>/<stage>/`. Historical
research notes live in `docs/archive/`; generated/imported material is under
`artifacts/archive/`. `.scratch/` is temporary, not a project memory system.

## Run one stage

Use existing images (`aerial-svd-jax:cpu`, `aerial-svd-jax:cuda12`), or build them
using [docs/jax.md](docs/jax.md). No host Torch/JAX installation is needed.
The launcher mounts only this repo, disables container networking, passes the code
revision, and runs as your UID/GID. It does not choose experiments or chain stages.

```bash
scripts/run.sh cpu python -m aerial_svd.lowrank_baseline \
  --config configs/aid_vit_small.yaml \
  --checkpoint artifacts/checkpoints/jax/vit_small_protocol_v1.npz \
  --output-dir artifacts/experiments/my_run/00_baseline --batch-size 8 \
  --expected-top1 0.9733333333333334 --top1-atol 0.005

scripts/run.sh cpu python -m aerial_svd.lowrank_factor_checks \
  --config configs/aid_vit_small.yaml \
  --checkpoint artifacts/checkpoints/jax/vit_small_protocol_v1.npz \
  --output-dir artifacts/experiments/my_run/01_factor_checks \
  --scope all_blocks --matrices blocks.0.attn.proj --rank-ratios 0.5 0.75 1.0

scripts/run.sh cpu python -m aerial_svd.lowrank_matrix_curves \
  --config configs/aid_vit_small.yaml \
  --checkpoint artifacts/checkpoints/jax/vit_small_protocol_v1.npz \
  --output-dir artifacts/experiments/my_run/02_matrix_curves \
  --scope all_blocks --matrices blocks.0.attn.proj --rank-ratios 0.25 0.5 0.75 1.0
```

Each stage requires a fresh output directory and records input/output hashes in
its own manifest. Stage 00 evaluates validation only; 01 tests real factors and
full rank; 02 computes analytic matrix errors without image inference. Full
interfaces and schemas: [stage guide](docs/lowrank/RUN_STAGES_RU.md).

Use `gpu` plus the stage's `--device gpu` for GPU work. The launcher first checks
for compute jobs and refuses a busy/inaccessible GPU. In agent sandboxes that hide
NVIDIA devices, run with the necessary host access; that is not a driver repair.
The optional `scripts/lowrank_series.py` enumerates explicitly requested SVD series;
independent 04–08 commands are in the stage guide. Activation-aware experiments remain separate.

## Check and maintain

```bash
scripts/check.sh                 # shell/Python checks + workspace/native CLI tests
./fix_permissions.sh             # repair existing generated files through Docker
```

Both Dev Container profiles create a non-root `research` user and synchronize its
UID/GID with the Linux host. Rebuild/reopen an old root container to adopt this.
The ownership repair uses the existing CPU image with a read-only container root;
it touches only `artifacts/`, `.scratch/`, `.cache/`, never follows symlinks, and
needs Docker access, not host sudo. No sudoers change is required.

Update `WORK_LOG.md` after substantive tasks: outcome, proof, remaining issue.
Keep commands in the guide and scientific provenance with results. Do not create
another workflow, transcript, task packet or report just to record ordinary work.
